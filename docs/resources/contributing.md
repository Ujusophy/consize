# Contributing

Consize is completely open for contribution. Whether it's fixing bugs, adding support for new cloud providers, or improving documentation, we welcome all of it.

* [Testing](testing.md) — how to run the test suite locally
* [E2E Tests](e2e.md) — end-to-end test setup and conventions

For larger changes, open a GitHub Discussion first. Significant decisions get recorded as [Architecture Decision Records](decisions.md).
